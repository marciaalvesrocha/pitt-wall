# Pit Wall · GP de São Paulo 🏎️🇧🇷

Este é um projeto de estudo focado em **HTML5** e **CSS3**, criando uma landing page responsiva para o Grande Prêmio de São Paulo de Fórmula 1 (edição fictícia/futura de 2026, com o piloto brasileiro Gabriel Bortoleto). 

A página simula um portal de informações e venda de ingressos para a corrida no Autódromo de Interlagos.

## 🚀 Funcionalidades

A página é dividida em três seções principais:
- **Grid de Pilotos:** Apresenta os principais pilotos e suas equipes (Ferrari, McLaren, Mercedes, Audi) usando um layout em CSS Grid.
- **Classificação:** Uma tabela detalhada com as posições, pontos e diferenças do campeonato, além de um formulário de busca/filtro visual.
- **Ingressos:** Um formulário de reserva de ingressos interativo, incluindo seleção de setores, quantidade e upload de foto.

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estruturação semântica (tags como `<header>`, `<main>`, `<section>`, `<article>`, etc).
- **CSS3:** 
  - Layouts modernos utilizando **Flexbox** e **CSS Grid**.
  - Variáveis CSS (Custom Properties) para paleta de cores (temática dark/neon) e fácil manutenção.
  - Estilização de formulários e tabelas.
  - Design Responsivo (Media Queries) adaptado para dispositivos móveis (telas menores que 768px).
- **Google Fonts:** Utilização da fonte *Titillium Web* para trazer um visual tecnológico e esportivo.

## 📁 Estrutura de Arquivos

- `index.html`: Contém toda a estrutura e conteúdo da página.
- `styles.css`: Contém os estilos e regras de design.
- `img/piloto.jpg`: Imagem de fundo utilizada na seção principal (Hero).

## 💻 Como executar o projeto

1. Faça o download ou clone este repositório.
2. Certifique-se de que a estrutura de pastas está correta (a imagem `piloto.jpg` deve estar dentro de uma pasta chamada `img`).
3. Dê um duplo clique no arquivo `index.html` para abri-lo em seu navegador padrão.
4. *Opcional:* Para uma melhor experiência de desenvolvimento, você pode usar a extensão "Live Server" no VS Code.
